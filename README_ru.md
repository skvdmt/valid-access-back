# Проверка токена доступа

### Translations
[En](./README.md)

### Описание
Используется для проверки токена доступа на бэкенде.

Соединение с сервером устанавливается по протоколу gRPC.

Используется при проверке токена, выданного [API аутентификации](https://secret.skvdmt.ru/api/auth/v1/doc).
